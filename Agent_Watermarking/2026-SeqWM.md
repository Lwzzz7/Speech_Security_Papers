# Sequential Behavioral Watermarking for LLM Agents（SeqWM）

## 0. 摘要

本文提出 **SeqWM**，用于给 LLM Agent 的动作轨迹嵌入行为水印。现有逐步水印通常用绝对轮次生成 keyed action subset，把每一步视为独立试验；一旦轨迹中删除一个动作，后续动作与轮次索引全部错位，检测信号迅速坍塌。SeqWM 将载体从“第 t 步选择了什么”改为“给定最近 w 个动作后，下一个动作如何转移”，并使用多通道冗余、滑动窗口检测和随机错误 key 校准。这样，删除或截断只破坏局部窗口，不再令整条轨迹永久失配。

在 ToolBench、ALFWorld 和 OASIS Reddit，以及 Gemma、LLaMA、Qwen 三类模型上，SeqWM 的真实 key 均取得显著检测结果，同时保持 Agent 任务效用；在删除攻击下，其优势尤其明显。论文目前为 2026 年 arXiv 预印本，官方代码已经公开。

## 1. 问题定义与威胁模型

Agent 在第 t 步从候选动作集合中选择动作。检测者只能观察最终动作序列，不依赖隐藏 token、logits 或完整环境状态。攻击者可以删除、截断、替换或只公开部分轨迹，但不知道秘密 key。

编码器与检测器共享秘密 key K。对任意上下文 x，通过 HMAC 派生大小为 n 的伪随机动作子集：

$$G_K(x)=\mathrm{SampleSubset}(\mathcal{B}_t,\mathrm{HMAC}(K,x),n)$$

若动作集合大小为 A，则错误 key 在任一通道上的自然命中率为 p0=n/A。

## 2. 现有逐轮水印为何脆弱

传统方法用绝对索引 t 作为随机种子，并提高 keyed subset 中动作的概率。它存在两个结构性问题：

1. 水印直接改变一阶动作频率，攻击者可以估计并矫正边缘分布。
2. 编码器和检测器必须共享绝对位置；任意删除都会让后续全部位置错位。

在删除率固定时，逐轮检测器保留的有效信号只来自第一次删除之前的短前缀，其期望优势不会随长轨迹线性增长。

## 3. 方法设计与复现级理解

### 3.1 历史条件种子

SeqWM 不使用轮次编号，而用最近 w 个动作构成上下文：

$$c_t=(b_{t-w},\ldots,b_{t-1}),\qquad B_{g,t}=G_K(c_t)$$

同一局部历史无论出现在轨迹何处，都会导出同一 guided subset。因此检测器无需知道原始绝对位置；水印改变的是条件转移分布，而不是简单提高某一动作的全局频率。

### 3.2 多通道冗余

方法将通道索引 j 拼接到上下文，每个通道独立生成 subset：

$$B_{g,t}^{(j)}=G_K(c_t\Vert j),\qquad j=1,\ldots,m$$

对候选动作 b，统计其跨通道命中数 s_t(b)。水印分布在原模型概率上加入指数偏置：

$$P_t^{wm}(b)=\frac{P_t(b)\exp(\gamma s_t(b)/m)}{\sum_{b'}P_t(b')\exp(\gamma s_t(b')/m)}$$

其中 gamma 控制检测强度，m 通过冗余降低单通道随机性。为避免极低概率动作因水印获得过大相对提升，论文还使用概率 floor delta。

### 3.3 检测能力与效用代价

小 gamma 下，每步分布偏移的 KL 代价近似为：

$$D_{KL}(P_t^{wm}\Vert P_t)=\frac{\gamma^2}{2m}p_0(1-p_0)+O(\gamma^3)$$

这揭示了一个有用的设计关系：增加通道数 m 可以降低每步分布扰动，但检测端仍能聚合多个通道的命中证据。

### 3.4 无绝对位置的滑动窗口检测

检测器遍历观测序列的所有长度 w+1 子串，把前 w 个动作当上下文、最后一个动作当待验证转移，并累计其在 m 个 keyed subset 中的命中次数：

$$S(K,\hat b)=\sum_{i=1}^{T'-w}\sum_{j=1}^{m}\mathbf{1}[\hat b_{i+w}\in G_K(\hat b_{i:i+w-1}\Vert j)]$$

若删除 d 个动作，每个删除最多污染包含它的 w 个上下文以及一个 next-action 位置，因此得分下降存在确定性界：

$$S(K,\hat b)\geq S(K,b_{1:T})-d(w+1)m$$

这并不保证任意删除率下必然检出，但说明破坏是局部且可计数的，而非一次删除导致全局错位。

### 3.5 随机 key 校准

滑动窗口彼此重叠，动作本身也具有时序相关性，因此不能把所有命中当作独立 Bernoulli 变量套用二项 z 检验。SeqWM 用 M 个随机错误 key 在同一条观测轨迹上计算零假设得分，并以真实 key 的秩计算有限样本 p 值：

$$p=\frac{1+\sum_{r=1}^{M}\mathbf{1}[S(K_r,\hat b)\geq S(K,\hat b)]}{M+1}$$

在无水印假设下，真实 key 与错误 key 可交换，因此该检验不要求知道 Agent 的动作分布，也不要求 T 很大。

## 4. 实验设置

| 项目 | 配置 |
|---|---|
| Benchmark | ToolBench、ALFWorld、OASIS Reddit |
| 规模 | ToolBench 200 queries；ALFWorld 50 tasks；OASIS 100 simulation steps |
| 模型 | LLaMA-3.2-3B-Instruct、Gemma-4-E4B-it、Qwen3-4B-Instruct |
| 解码温度 | 0.7 |
| 默认参数 | w=3，m=8，n=3；OASIS 使用 n=2 |
| 其他参数 | delta=0.2，gamma=2.0 |
| 校准 | M=1000，显著性阈值 alpha=0.01 |
| 对照 | Unwatermarked、AgentGuide、AgentMark |

主实验在 NVIDIA A100 上运行，部分分析使用 RTX PRO 6000 Blackwell。

## 5. 主要实验结果

### 5.1 检测

SeqWM 在全部九个“模型×任务”组合上达到显著检测。Gemma 的 ToolBench/ALFWorld/OASIS 真实 key p 值均为 0.001；LLaMA 也均为 0.001；Qwen 分别为 0.001、0.001 与 0.010。相较之下，AgentGuide 和 AgentMark 在多个组合上无法与错误 key 零分布分离。

### 5.2 经验均值与理论一致性

ToolBench、ALFWorld、OASIS 的理论得分增量与实测值比值分别约为 1.12、0.91、1.42，说明小偏置的一阶近似能够解释主要检测信号，但在有限长度和非均匀动作分布下仍有常数级偏差。

### 5.3 删除鲁棒性

逐轮索引方案删除一次后会持续错位；SeqWM 的删除只影响邻近窗口。因此在不断提高删除率时，SeqWM 的检测能力平滑下降，而逐轮与基于固定位置的编码方案更早坍塌。

## 6. 参数与消融理解

- gamma 增大时检测信号增强，但 KL 代价近似按 gamma 的平方增长。
- w 太小会让上下文区分度不足；w 太大则使一次删除污染更多窗口，并提高重复上下文稀疏性。
- m 增加可提供冗余并降低每通道偏置，但检测和采样计算量线性增长。
- M 决定 p 值分辨率。M=1000 时最小可报告值约为 0.001；因此大量结果等于 0.001 只表示真实 key 排名第一，并不代表精确尾概率。

## 7. 贡献与优点

1. 将 Agent 水印从独立步骤信号转为历史条件转移信号，真正利用轨迹的序列结构。
2. 滑动窗口消除了编码器与检测器对绝对位置对齐的依赖。
3. 随机错误 key 校准避免错误的独立二项假设，并提供有限样本假阳性保证。
4. 理论分析明确给出删除造成的局部证据损失上界及效用—检测权衡。

## 8. 局限性与批判性分析

1. **有限动作集合假设较强。** ToolBench、ALFWorld、OASIS 可以抽象为候选行为集合；开放式代码、自由参数 API 或自然语言动作需要额外离散化。
2. **主要理论针对删除。** 替换、重排、语义合并和策略重规划可能同时改变上下文与 next action，局部界不再直接适用。
3. **随机 key 检验保证的是假阳性，不保证功效。** 强攻击下真实 key 与错误 key 得分都可能降低，p 值仍有效但无法检出。
4. **同一轨迹上的错误 key 并非真实世界多模型负样本。** 仍需跨服务、跨模型和跨脚手架验证误报率。
5. **水印插入需要操纵动作分布。** 对只返回最终动作、不给候选 logits 的闭源 Agent，部署者必须控制选择层或重新实现采样接口。

## 9. 与 ActHook 和 AgentWM 的关系

ActHook 保护训练轨迹数据，通过秘密文本 key 诱导额外 hook action；AgentWM 在功能等价工具路径之间编码用户指纹；SeqWM 则直接在部署期动作选择分布中植入历史条件信号。三者分别对应“数据是否被用于训练”“某个 Agent 实例是否属于供应商”“一条行为轨迹是否来自带水印策略”三个相近但不同的归因问题。

## 10. 复现建议

1. 先在有限离散动作环境复现无攻击检测，并保存每步原分布、水印分布和通道命中数。
2. 用同一条轨迹、同一组错误 key 复算 p 值，确认最小 p 值受 M+1 限制。
3. 同时报告任务成功率、平均 KL、动作边缘分布差异与真实 key 得分，不只报告 p 值。
4. 删除攻击应固定删除比例、随机种子和删除位置策略，并加入开头集中删除与自适应删除。
5. 对连续或带参数动作，预先定义等价动作归一化规则，否则检测器无法稳定比较。

## 11. 可延伸研究方向

- 学习型上下文哈希，使语义相近但表面不同的动作窗口得到稳定种子。
- 为替换、重排和局部摘要构造编辑距离或序列对齐检测器。
- 将多通道从重复单比特信号扩展为纠错编码的多用户指纹。
- 研究多个水印策略叠加、串谋用户混合轨迹以及跨模型蒸馏后的归因。
- 在真实浏览器、代码 Agent 和长期任务上评估时延与任务质量成本。

# Countering Neural Audio Codec Distortions in Watermarking with Adaptive Restoration

> 精读依据：ISCA 会议信息页及会议 PDF 全文，核验日期 2026-10-05。这里的 restoration 是检测端频谱恢复，不是用于播放的音频增强。

## 0. 摘要翻译

神经音频codec具有较高压缩效率，但会产生结构性、非线性失真，严重削弱音频水印。为此，本文提出具备codec感知能力的自适应恢复框架，在提取水印之前重建受codec破坏的频谱。方法采用ConvNeXt U-Net恢复细粒度频谱模式，并引入轻量分类器，为每种codec动态选择专用恢复模型。多种神经codec实验显示，该方法能使RVQ类codec的比特准确率从接近随机提升到98%以上。作者还分析量化器配置对水印存活的影响，表明该方法可以提升现代codec环境下的水印鲁棒性。

## 1. 研究动机

更换或重新训练嵌入器会影响已有水印系统与历史内容。作者选择在检测端加一个模块：已有 Timbre 水印的微弱证据如果没有被完全丢弃，能否从 codec 失真中恢复？这使问题由重新嵌入转为“保留原水印与原解码器，学习逆向校正输入频谱”。

它与 Latent-Mark 的区别在优化位置：Latent-Mark 改发布波形，本文改检测输入；与库中 WMCodec 的区别在于不在压缩 codec 内嵌水印。对无法找回的信息，恢复网络不会凭空创造可靠的原消息。

## 2. 威胁模型

| 维度 | 设定 |
|---|---|
| 参与方 | Timbre 嵌入/解码系统、外部神经 codec、恢复与路由模块 |
| 攻击目标 | 压缩后使消息无法正确归因；主体实验为通道变换而非对抗优化 |
| 攻击能力 | 选择 codec 与码率，重建水印音频；无秘密消息梯度攻击 |
| 防御能力 | 有原水印模型，可生成配对压缩样本；可训练多个恢复器和 codec 分类器 |
| 输入/输出 | 输入受压缩波形；输出消息比特/归因结果；不把恢复音频交给用户播放 |
| 知识边界 | 路由器在已知 codec 集合中分类；专用网络见过相应 codec 训练样本 |
| 约束 | 兼容原解码器、恢复可检测证据；质量主张不涉及恢复波形的听感 |

现实性分析：服务端可集成预处理器，适合已有内容的兼容检测。强假设是知道候选 codec 并能训练专用恢复网络；未知 codec、组合处理、错误路由和自适应针对分类/恢复器的攻击没有系统验证。后文的100%分类准确率是封闭已知集结果，不能解释为任意 codec 可准确识别。

## 3. 方法设计与复现级解读

### 3.1 全局数据流

训练：音频 $x$ → 原 Timbre 编码器嵌入消息 → 水印音频 $x_w$ → 选 codec 压缩重建得到 $x_c$ → 提取受损幅度谱 $S_c$ → 专用恢复器预测 $\hat S_w$ → 与原水印幅度谱 $S_w$ 比较 → 更新恢复器。另用已知 codec 类别训练分类器。

部署：$x_c$ → codec 分类 → 选择专用恢复器 → 幅度谱恢复 → 原水印解码器 → 比特与归因。原嵌入器无需再训练；用户播放的仍是接收到的压缩音频。

### 3.2 基础水印与恢复目标（原文方法部分）

原系统把水印沿时间重复，并在提取时通过时间池化降低扰动。压缩后的频谱既包含语音内容变化，也包含残余水印变化。恢复器输入为固定尺寸的512×512频谱，目标是压缩前**带水印**频谱，而非干净无水印频谱：

$$L_{rec}=\|F_c(S_c)-S_w\|_1$$

$F_c$ 为 codec $c$ 的专用网络。L1 逐元素惩罚恢复误差，更新的是恢复器参数。若误用无水印 $S$ 为训练标签，训练目标会直接鼓励删水印，属于关键实现错误。

正文展示频谱恢复，不意味着网络显式监督每个消息 bit。训练损失追求频谱相似，水印解码准确率用于检验该相似是否保留归因信息。语音结构较强时，频谱重建损失也可能偏向语音而忽视微弱标记，所以最终必须以消息指标检查。

### 3.3 ConvNeXt U-Net 恢复器

网络有9个分辨率层级、8次下采样，保持 U-Net 的编码—解码与跨层跳连。所有基础卷积模块替换为 ConvNeXt 风格模块，其中7×7深度卷积用于扩大局部感受野。跳连把较浅频谱细节传给对称解码层，较深层建模 codec 引入的结构变形。

输入输出均为同尺寸频谱，恢复器不直接生成消息。论文没有充分汇总各层完整通道、归一化、STFT窗/步长、音频裁切与512×512映射，不能凭常见 U-Net 设置补造。对于变长音频，分段/拼接规则也是部署缺口。

### 3.4 codec 识别与专家路由

11种 codec 分别训练恢复器。轻量分类器从压缩音频的表示判断 codec 类型，再选择专家。它解决的是“不同 codec 失真不同、单恢复器难以兼顾”。与不路由的共同模型相比，专用网络可学习更窄的逆映射。

分类器输出离散类别；路由不是同时对所有专家加权融合。若 codec 未见过，强制选择某个专家可能产生错误校正。分类器的完整架构、训练优化配置、未知类别拒识阈值，当前正文未充分提供。分类实验不包含开放集未知 codec，故不能扩展为开放集安全机制。

### 3.5 一轮训练与推理分离

每轮取原音频和消息，使用冻结嵌入器/codec 产生配对频谱，专用网络前向并计算L1，反传只更新恢复参数。每个专家独立训练；验证损失选择最佳检查点。部署只运行分类器、选中的恢复器、原解码器，不再使用原始音频或原消息标签。

方法分别应对已知 codec 选择和保留残余证据；它没有修改 codec 压缩路径，因此对信息已经彻底丢弃的极低码率情形，网络不存在可保证的恢复能力。

## 4. 与其他方法对比

| 类别 | 思想 | 优点 | 局限 | 本文改进 |
|---|---|---|---|---|
| 原 Timbre | 直接解码压缩音频 | 原系统简单 | codec 降低比特/整消息准确率 | 加检测端恢复 |
| 通用频谱恢复 | 一个模型覆盖失真 | 部署模型数少 | 不同 codec 逆映射冲突 | 分类选择专家 |
| 基础 CNN 专家 | 局部卷积恢复 | 结构容易实现 | 结构失真建模较弱 | ConvNeXt U-Net |
| 重新训练嵌入器 | 嵌入时适应 codec | 可提前保留信息 | 不直接兼容旧内容 | 本文可接已有解码器 |

## 5. 实验表现与优势

### 5.1 指标

Bit Accuracy 是正确比特占比；Attribution Accuracy 是整条消息全部正确的比例。50% bit accuracy 对均衡比特接近随机猜测，并不意味着有50%音频能可靠归因。整消息指标通常远低于逐比特指标，本文同时报告两者较有价值。

### 5.2 神经 codec 结果

| codec / 码率 | Bit Acc. 原→恢复(%) | Attribution 原→恢复(%) |
|---|---:|---:|
| EnCodec 6kbps | 59.00→84.05 | 0.38→26.15 |
| EnCodec 12kbps | 68.33→97.03 | 2.75→78.62 |
| EnCodec 24kbps | 72.91→98.75 | 5.34→90.46 |
| DAC44.1k 8kbps | 86.56→99.58 | 23.21→96.15 |
| FunCodec 16kbps | 59.60→98.03 | 0.46→84.69 |
| AudioDec 12.8kbps | 60.09→94.23 | 0.31→66.15 |
| SpeechTokenizer 4kbps | 54.53→69.78 | 0→3.46 |
| Mimi 1.1kbps | 60.55→88.70 | 0.38→40.00 |
| BigCodec 1.04kbps | 51.95→54.38 | 0.15→0.23 |
| WavTokenizer 0.9kbps | 49.91→51.15 | 0→0.15 |

表1显示码率和量化结构共同影响效果。EnCodec1.5kbps仅从51.61到51.95%，HiFiCodec1.6kbps从56.85降到55.82%，并非所有 codec 都获益。多层 RVQ 的残余表示更可能携带微弱水印；单量化器低码率结果接近随机。因码率、架构与训练目标共同变化，这支持相关解释，未单独证明“量化器数量”的因果作用。

### 5.3 消融与路由

表2在EnCodec6kbps上：完整方法84.05/26.15（比特/归因）；基础CNN但保留路由70.44/4.66；无路由60.54/2.67；无恢复59.01/0.31。恢复结构和专门化都有效。表1/2的未恢复基线有微小差异，应按各表记录，不强行统一。

分类器在11种codec、每类1310条、总14,410条测试样本上达100%分类准确率；这是同分布已知类测试。恢复器在单说话人LJSpeech训练，跨语言、多说话人、未见codec泛化没有该数字所暗示的覆盖。

### 5.4 保真度、常规攻击与容量

恢复器只服务检测，不改变用户听到的音频，论文未提供恢复后播放质量的完整MOS/PESQ比较；不能称其恢复了高保真波形。主体实验没有DSP组合攻击、VC/ASR-TTS或攻击者针对恢复器的优化。未给完整容量扩展、FPR约束下的归因安全性与专家运行成本。

## 6. 学习与应用

当前原文没有核实到官方代码仓库，Code应标为“未确认公开”。最小复现可以只选EnCodec6/12kbps与一个Timbre模型，先把配对频谱与原解码接口跑通，再比较基础CNN和ConvNeXt。建议先测整消息准确率和未标记音频误归因，再扩展专家数量。该建议属于复现设计，不是已执行实验。

可用于历史水印内容的检测兼容层。对自己的水印实验，可把检测前恢复作为补充防御，但必须和“嵌入器本身抗codec”分开报告；训练使用目标codec也应明确属于已知通道适配。

## 7. 总结

按codec恢复检测端水印频谱。

## 9. 复现难度与适合人群

难度中高。主要依赖Timbre权重、11种codec、配对谱生成、RTX4090级训练和未披露分类器细节。最小单codec版本难度中等，多专家完整版本成本较高。适合已有水印系统维护、检测端鲁棒性改造和codec信息保留研究。

## 10. 简短全面总结

本文针对神经音频codec破坏现有水印的问题，提出检测端自适应频谱恢复，而不重新训练原水印嵌入器。训练时用Timbre生成水印音频，经各codec压缩后提取受损幅度谱，以压缩前带水印频谱作为L1恢复目标；部署时轻量分类器识别codec，选择对应ConvNeXt U-Net专家，再交给原解码器。恢复器使用九个分辨率层级和跳连，分别针对十一种codec训练。在LJSpeech划分上，DAC8kbps比特准确率从86.56%提升到99.58%，整消息归因从23.21%提升到96.15%；EnCodec24kbps也达98.75%比特准确率，但极低码率单量化器codec仍接近随机。消融说明专用路由与网络结构都影响恢复效果。该工作支持部分codec失真后仍残留可利用的水印证据，主要限制是已知codec与单说话人训练设定、未知通道泛化未验证，以及恢复只用于检测，不能外推为高质量音频增强。

## 11. 论文写作逻辑分析

作者从codec结构失真引出恢复需求，以兼容现有水印系统形成清楚的工程动机。方法先定义恢复对象，再用专家路由解释自适应，是自然顺序。表1同时给成功和失败codec，比只给平均提升更能说明适用条件；表2对应两个核心模块，证据组织紧凑。

写作中应进一步明确检测端恢复与播放增强的边界，并收缩“量化器数量决定存活”的因果表述。复现配置和开放集评测不足影响完整性。可借鉴其逐码率、逐比特及整消息双指标展示方式；在自己的论文中应补充跨域、未知codec、误报和运行成本以完善部署论证。
